# 🚀 Quick Start Guide - DevFlow Project\n\n## Prerequisites\n\nBefore you begin, ensure you have installed:\n- **Node.js** 18+ ([Download](https://nodejs.org/))\n- **npm** or **yarn** (comes with Node.js)\n- **Git** ([Download](https://git-scm.com/))\n\n## ⚡ Quick Setup (5 minutes)\n\n### Step 1: Install Dependencies\n\n```bash\ncd d:\\Next.js\\devflow\nnpm install\n```\n\n### Step 2: Environment Configuration\n\nCreate `.env.local` in the project root:\n\n```env\n# Supabase\nNEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co\nNEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key\n\n# OpenAI (for AI features)\nOPENAI_API_KEY=your-openai-key\n\n# Email (Resend)\nRESEND_API_KEY=your-resend-key\n\n# Stripe (for payments)\nSTRIPE_SECRET_KEY=your-stripe-secret\nSTRIPE_PUBLISHABLE_KEY=your-stripe-publishable\n\n# Analytics\nNEXT_PUBLIC_POSTHOG_KEY=your-posthog-key\nNEXT_PUBLIC_POSTHOG_HOST=https://app.posthog.com\n```\n\n### Step 3: Start Development Server\n\n```bash\nnpm run dev\n```\n\n🎉 Open [http://localhost:3000](http://localhost:3000) in your browser!\n\n---\n\n## 📝 Available Scripts\n\n| Command | Purpose |\n|---------|--------|\n| `npm run dev` | Start development server (hot reload) |\n| `npm run build` | Build for production |\n| `npm start` | Start production server |\n| `npm run lint` | Run ESLint |\n| `npm run type-check` | Check TypeScript |\n| `npm test` | Run unit tests |\n| `npm run test:e2e` | Run end-to-end tests |\n\n---\n\n## 🔌 Connecting to Supabase\n\n### 1. Create Supabase Project\n- Go to [supabase.com](https://supabase.com)\n- Create new project\n- Copy `URL` and `Anon Key`\n- Paste into `.env.local`\n\n### 2. Run Database Migrations\n\n```bash\n# Using Supabase CLI\nsupabase db push\n```\n\nOr manually run SQL from `supabase/migrations/`:\n- Open Supabase SQL editor\n- Copy & paste migration file contents\n- Execute\n\n### 3. Enable Auth\n\n- Go to Supabase Dashboard → Authentication → Providers\n- Enable: Email/Password, GitHub, Google\n- Set redirect URLs to `http://localhost:3000/auth/callback` (dev)\n\n---\n\n## 🎨 Project Layout\n\n```\nsrc/\n├── app/              # Pages and API routes\n├── components/       # React components\n├── lib/              # Utilities and hooks\n├── store/            # Zustand state\n└── types/            # TypeScript types\n```\n\n---\n\n## 🔑 Key Features\n\n### Authentication\n- Email/password login\n- OAuth (GitHub, Google)\n- Password reset\n- Session management\n\n### Dashboard\n- KPI metrics\n- Project progress charts\n- Activity feed\n- Deadline alerts\n\n### Projects & Tasks\n- Create/edit/delete projects\n- Kanban board\n- Task filtering and search\n- Team collaboration\n\n### Admin Panel\n- User management\n- AI usage tracking\n- Audit logs\n- Workspace settings\n\n### AI Features\n- Bug analysis\n- Project decomposition\n- Smart deadline estimation\n- Auto-generated standups\n\n---\n\n## 🧪 Testing\n\n### Run Unit Tests\n```bash\nnpm test\n```\n\n### Run E2E Tests\n```bash\nnpm run test:e2e\n```\n\n### Create Test Files\n```typescript\n// tests/unit/example.test.ts\nimport { describe, it, expect } from 'vitest'\n\ndescribe('Example Test', () => {\n  it('should work', () => {\n    expect(1 + 1).toBe(2)\n  })\n})\n```\n\n---\n\n## 📦 Build & Deploy\n\n### Build for Production\n```bash\nnpm run build\n```\n\nThis creates an optimized build in `.next/` directory.\n\n### Deploy to Vercel (Recommended)\n\n1.
